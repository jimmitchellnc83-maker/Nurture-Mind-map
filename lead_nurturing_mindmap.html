⚙️ 4 AUTOMATED WORKFLOWS

These automation sequences manage the entire lifecycle

🎯 WORKFLOW A: Track Management

TRIGGERS:
  • Property changes
  • Form submissions
  • Page views & downloads
  • Engagement events
ACTIONS:
  • Update track_current based on score
  • Set highest_track_reached
  • Advance contacts through tracks

🔐 WORKFLOW B: CRM Status Control

TRIGGERS:
  • Lifecycle stage updates
  • Deal creation/closure
  • SQL/Opportunity status
ACTIONS:
  • PAUSE nurture (track_state = Paused)
  • Set reentry_eligibility_date
  • Stop all nurture sends

🔄 WORKFLOW C: Re-entry Logic

TRIGGERS:
  • Return to marketing-qualified
  • Recycle status activated
  • Deal closed-lost
CONDITIONS:
  • reentry_eligibility_date reached
  • crm_open_opportunity = false
ACTIONS:
  • ACTIVATE (track_state = Active)
  • Resume at saved checkpoint

✅ WORKFLOW D: Checkpoint Tracking

TRIGGERS:
  • Successful message delivery
  • Content module completion
ACTIONS:
  • Increment track_checkpoint by 1
  • Mark "Completed" when done
  • Save progress for next send

🔄 CRM SYNCHRONIZATION

📥 Lifecycle Sync

CRM lifecycle status automatically updates crm_lifecycle_stage field via bidirectional sync

💼 Deal Triggers

Deal creation/closure updates crm_open_opportunity to control nurture pause/resume

⏸️ Sales Pause

SQL/Opportunity/Customer status sets track_state = Paused automatically

♻️ Recycle Logic

Recycle/Closed-Lost waits for reentry_eligibility_date then reactivates

🗂️ 10 CORE CUSTOM PROPERTIES

📊 track_current

Dropdown: Awareness, Research, Qualification, Hot

Controls which nurture stream the contact is currently enrolled in

📍 track_checkpoint

Number

Stores the index of the next module to send - enables resume from exact position

🏆 highest_track_reached

Dropdown

Prevents regression - records the highest track entered

⚙️ track_state

Dropdown: Active, Paused, Completed

Controls whether nurture sequences are currently running

📝 track_reason

Text

Documents why a track was paused, resumed, or changed

🔄 crm_lifecycle_stage

Dropdown

Mirrors the CRM lifecycle status of contact/account

💼 crm_open_opportunity

Boolean: Yes/No

Indicates if an active deal is associated with the contact

📅 reentry_eligibility_date

Date

Sets future re-engagement date after disqualification/recycle

📈 score_current

Number

Most recent engagement/behavior-based lead score

⚡ velocity_7d

Number

Measures 7-day engagement acceleration for trigger logic

🛡️ DATA SAFEGUARDS

💾 Persistent Properties

All key values remain persistent even when contact exits automation

🔒 No Auto-Clear

System never clears track_checkpoint or highest_track_reached unless manually reset

✅ Controlled Re-enrollment

Re-enrollment requires track_state = Active, ensuring correct position

🛡️ Prevents Issues

Prevents duplication, looping, and premature restarts of sequences
