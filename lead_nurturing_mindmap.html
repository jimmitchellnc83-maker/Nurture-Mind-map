🎯 How The System Works - 6 Phases

Phase 1: Entry & Initialization

New contacts enter the system and are initialized with track_state = Active and track_checkpoint = 1

Phase 2: Track Assignment

Score evaluation routes contacts to one of 4 tracks: Awareness, Research, Qualification, or Hot based on engagement level

Phase 3: Nurture Send & Checkpoint

System sends nurture message at the checkpoint index, then Workflow D increments the checkpoint by 1

Phase 4: CRM Checks & Pause Logic

Workflow B checks CRM status. If SQL/Deal/Customer, pauses nurture. Workflow C handles re-entry after recycling

Phase 5: Engagement Check

Workflow A monitors engagement. If increased, updates track and re-evaluates. Otherwise, waits for next send

Phase 6: Completion

When all modules are completed, marks track_state = Completed and contact exits the nurture cycle
